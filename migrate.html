🔄 Migración de datos

Esta herramienta sube tus datos locales (álbumes, películas, series, listas…) a la nube de Firebase para que estén disponibles desde cualquier dispositivo.

Solo necesitas hacer esto una vez.
La migración lee tu base de datos local (IndexedDB) y la copia a Firestore bajo tu cuenta. Tus datos locales no se borran.
Comprobando sesión…
